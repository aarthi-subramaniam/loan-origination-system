# Project Overview

Business flow:
1. Customer enters loan details.
2. React sends the application to Spring Boot.
3. Backend validates credit score, income and loan amount.
4. Eligibility rules determine approval or rejection.
5. MySQL stores the application.
6. React displays the status.
